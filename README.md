# PORTFOLIO | Queralt Martín-Saladich, PhD

This repo hosts my professional portfolio, highlighting my research in AI/ML for Healthcare and scientific divulgation. If you find it helpful, feel free to use the template (just not the actual content) - and if you do, I'd appreciate if you acknowledge my work :)

**🌐 Live Site:** [https://queraltmartinsaladich.github.io/qms.github.io/](https://queraltmartinsaladich.github.io/qms.github.io/)

---

## 🛠️ Tech Stack
* **HTML5 / CSS3**
* **Tailwind CSS** (via CDN for rapid styling)
* **Google Fonts & Fontshare** (Playfair Display, Glacial Indifference, EB Garamond)
* **GitHub Pages** (Hosting)

## 📂 Project Structure
* `index.html` - Home page & Bio
* `education.html` - Academic background
* `experience.html` - Research & Professional history
* `publications.html` - Peer-reviewed journals & proceedings
* `conferences.html` - Talks and poster presentations
* `divulgation.html` - Science communication & outreach
* `skills.html` - Digital, soft skills, and languages

## 🚀 Key Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
- **Academic Aesthetic:** Clean, typography-focused design using a professional color palette.
- **Dynamic Content:** Integrated LinkedIn-style cards for research updates and divulgation activities.
