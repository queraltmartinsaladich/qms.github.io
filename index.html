Recent Updates & Insights

Amino-Map

I recently developed Amino-Map: An Interactive Protein Mutation Browser using JavaScript. Amino-Map is a specialized React-based dashboard designed for the exploration and analysis of protein variants. Developed as an interview test for the Beltrao Group (ETH Zürich), it bridges the gap between raw mutation data and biological context by integrating sequence visualization, 3D structural modeling, and functional annotations into a single, cohesive research tool.
